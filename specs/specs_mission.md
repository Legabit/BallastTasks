# Project Mission: Task Management System

## Core Purpose
Build a secure, high-performance, and maintainable Task Management System adhering strictly to Clean Architecture principles.

## Guiding Principles
- **Test-Driven Reliability:** Maintain $\ge 80\%$ test coverage across unit, integration, and contract test suites.
- **Robust Security:** Implement JWT auth with token rotation, object-level permissions, strict rate limiting, and secure headers.
- **Polished User Experience:** Deliver a fully responsive React frontend with zero browser console warnings and accessible UI patterns.
- **Developer Ergonomics:** Provide a single-command Docker environment (`docker-compose up`) with seeded demo data and automated CI checks.

# Tech Stack: Task Management System

- **Backend Language:** Python 3.12+
- **Backend Framework:** Django, Django REST Framework (DRF), Django REST Framework SimpleJWT
- **Database & Caching:** PostgreSQL 15+ (production/Docker), Redis (caching & Celery broker)
- **Asynchronous Tasks:** Celery for background notifications and reminders
- **Frontend:** React, modern build tool (Vite), responsive component design system
- **API Documentation:** `drf-yasg` (Swagger UI)
- **Tooling & Quality Assurance:** `pytest`, `pytest-django`, `pre-commit` hooks (linting/formatting), Docker & Docker Compose
